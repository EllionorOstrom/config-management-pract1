## Описание

В этом репозитории собраны решения 10 задач практического занятия №1.
Все скрипты написаны на **bash** и предназначены для запуска в Linux.

Цель работы — научиться:
- работать с файлами и каталогами из командной строки,
- использовать конвейеры (`|`) и перенаправление (`>`, `>>`),
- писать простые bash-скрипты,
- работать с регулярными выражениями (`grep`, `sed`, `awk`),
- архивировать файлы и искать дубликаты.

## Список файлов

| № | Файл | Что делает |
|---|------|------------|
| 1 | `task1.sh` | Выводит отсортированный список пользователей из `/etc/passwd` |
| 2 | `task2.sh` | Показывает 5 протоколов с наибольшими портами из `/etc/protocols` |
| 3 | `banner` | Выводит текст в рамке (размер зависит от длины текста) |
| 4 | `task4.sh` | Выводит все идентификаторы из файла C/C++ без повторений |
| 5 | `reg` | Регистрирует команду: даёт права и копирует в `/usr/local/bin` |
| 6 | `task6.sh` | Проверяет наличие комментария в первой строке файлов `.c`, `.js`, `.py` |
| 7 | `task7.sh` | Ищет файлы-дубликаты по содержимому |
| 8 | `task8.sh` | Архивирует все файлы с указанным расширением в `.tar` |
| 9 | `task9.sh` | Заменяет 4 пробела на табуляцию |
| 10 | `task10.sh` | Выводит имена пустых текстовых файлов в директории |
