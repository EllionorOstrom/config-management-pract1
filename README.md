# Эмулятор оболочки UNIX (вариант 17)

## Общее описание

Консольный эмулятор командной строки UNIX-подобной ОС на Python 3
(только стандартная библиотека). Практическая работа по дисциплине
«Конфигурационное управление».

Реализовано: этап 1 (REPL), этап 2 (конфигурация и стартовый скрипт).

## Функции и настройки

- Приглашение: `имя_пользователя@имя_хоста:~$` (данные реальной ОС).
- Парсер с поддержкой кавычек: `ls "my dir"`.
- Команды: `ls`, `cd` (заглушки), `exit`. Ошибки: неизвестная команда,
  лишние аргументы, незакрытая кавычка.
- Параметры командной строки:
  - `--vfs PATH` — путь к физическому расположению VFS;
  - `--script PATH` — путь к стартовому скрипту.
- При запуске выводится отладочная информация о всех параметрах.
- Стартовый скрипт: одна команда в строке; строки, начинающиеся с `#`,
  — комментарии. Каждая строка выводится так, как будто её ввёл
  пользователь, затем выводится результат. Ошибки в строках не
  прерывают скрипт. Если скрипт не завершился командой `exit`, эмулятор
  переходит в интерактивный режим. Нечитаемый скрипт — ошибка, код 1.

## Запуск и тесты

```
run.bat --script scripts\startup\basic.emu
scripts\test_stage2.bat
python -m unittest discover -v
```

## Пример

```
> run.bat --vfs vfs\minimal.zip --script scripts\startup\basic.emu
[debug] start-up parameters:
[debug]   vfs    = vfs\minimal.zip
[debug]   script = scripts\startup\basic.emu
user@host:~$ ls
ls []
user@host:~$ exit
```
