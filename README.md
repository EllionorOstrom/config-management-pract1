# Эмулятор оболочки UNIX (вариант 17)

## Общее описание

Консольный эмулятор командной строки UNIX-подобной ОС на Python 3
(только стандартная библиотека). Практическая работа по дисциплине
«Конфигурационное управление».

Этап 1 — REPL: приглашение к вводу, парсер с кавычками, команды-заглушки.

## Функции

- Приглашение формируется из данных реальной ОС: `имя_пользователя@имя_хоста:~$`.
- Парсер делит ввод по пробелам; аргументы в одинарных и двойных
  кавычках считаются одним аргументом (`ls "my dir"`).
- Команды:
  - `ls [args]`, `cd [args]` — заглушки, печатают имя и аргументы
    (у `cd` не более одного аргумента);
  - `exit` — выход (без аргументов).
- Ошибки: неизвестная команда, лишние аргументы, незакрытая кавычка.

## Запуск и тесты

```
run.bat
python -m unittest discover -v
```

## Пример

```
user@host:~$ ls -l "my dir"
ls ['-l', 'my dir']
user@host:~$ cd a b
cd: too many arguments
user@host:~$ foo
foo: command not found
user@host:~$ ls "x
parse error: unclosed quote "
user@host:~$ exit
```
